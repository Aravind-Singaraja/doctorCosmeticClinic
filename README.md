# Doctor's Hair Care Clinic — DrCC Chennai

Premium React website for **Doctor's Hair Care Clinic (DrCC)**, Chennai.

## Stack

- React 19 + TypeScript + Vite
- Framer Motion (scrollytelling / scroll reveals)
- Playfair Display + Poppins
- Bento layout · glassmorphism · dull white / soft grey

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
